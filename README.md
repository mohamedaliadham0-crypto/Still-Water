# Still Waters: get your APK
1. On github.com create a new repository (any name, public or private).
2. Click "Add file" > "Upload files", drag in everything from this folder (including the hidden .github folder), then "Commit changes".
3. Open the "Actions" tab. "Build APK" starts by itself (about 5 minutes). If not, choose it and press "Run workflow".
4. When it shows a green check, open the run and download "StillWaters-APK" at the bottom. Unzip it and install app-debug.apk on your phone (allow "install unknown apps").
Test in a browser anytime by opening index.html.
